# MENO

> **Read. Remain. Grow.**

MENO is a gamified Bible-reading mobile application designed to help users
start reading Scripture, follow a guided reading journey, and build a
consistent daily reading habit.

## ✨ Overview

Starting to read the Bible can be overwhelming.

New readers may not know where to begin, which reading path to follow,
or how to maintain a consistent reading habit.

MENO aims to make Bible reading feel more approachable by combining a
guided Scripture journey with simple habit-building and gamification
features inspired by modern learning applications.

Instead of focusing on teaching theology or providing extensive
interpretations, MENO focuses on helping users **read consistently**.

### Core Experience

**Choose a Journey → Read → Complete → Earn XP → Maintain Streak → Track Progress → Continue**

---

## 🎯 Project Goals

MENO aims to:

- Help beginners know where to start reading the Bible.
- Provide a structured and guided reading journey.
- Encourage consistent daily Scripture reading.
- Give users a clear sense of reading progress.
- Make Bible reading more engaging through lightweight gamification.
- Provide reminders to help users maintain their reading habit.

---

## 👤 Target Users

MENO is primarily designed for:

- Young adults and university students.
- People who want to start reading the Bible.
- Users who struggle to maintain a consistent reading habit.
- Users who prefer guided and interactive mobile experiences.

## 📖 Scripture Data

MENO is planned to use the Indonesian Literal Translation 3 (ILT3)
as its Scripture text source.

The application will organize Scripture data by:

**Book → Chapter → Verse**

Scripture data will be handled in accordance with applicable copyright
and distribution permissions.
